# DNS e Segurança

## O que é DNS?

DNS (Domain Name System) é o sistema utilizado para relacionar nomes de domínio a informações necessárias para localizar serviços e recursos em uma rede.

De forma simplificada, ele permite que usuários utilizem nomes em vez de precisar memorizar endereços IP.

## Por que DNS é relevante para Segurança?

O DNS faz parte do funcionamento cotidiano de praticamente qualquer ambiente conectado.

Durante uma investigação de segurança, consultas DNS podem ajudar a identificar:
- Domínios acessados;
- Comunicação com destinos suspeitos;
- Padrões incomuns de resolução;
- Indicadores relacionados a incidentes.

## Possíveis riscos

Entre os problemas que podem envolver DNS estão:
- DNS spoofing;
- DNS hijacking;
- Uso de domínios maliciosos;
- Abuso de DNS para comunicação ou exfiltração.
