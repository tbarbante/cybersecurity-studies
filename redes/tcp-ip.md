# TCP/IP — Fundamentos para Segurança

## Introdução

O conhecimento de redes é uma das bases importantes para a atuação em Segurança da Informação.

Compreender como dispositivos se comunicam ajuda a analisar tráfego, identificar comportamentos suspeitos e entender controles de segurança.

## Conceitos importantes

### IP
O Internet Protocol é responsável pelo endereçamento e encaminhamento de pacotes entre redes.

### TCP
O Transmission Control Protocol oferece comunicação orientada à conexão e mecanismos para entrega confiável dos dados.

### UDP
O User Datagram Protocol permite comunicação sem estabelecimento de conexão e possui menor sobrecarga que o TCP.

## Relação com Segurança

Conhecimentos de TCP/IP ajudam o profissional a compreender:
- Endereçamento;
- Portas;
- Protocolos;
- Fluxo de comunicação;
- Segmentação de redes;
- Regras de firewall;
- Análise de tráfego.
